Mindustry, ported
entirely to the web.

This project involves porting as much of Mindustry as possible.

This build forkes and modifies the engine Mindustry itself is built on, so its rendering, audio, and I/O layers target the web instead of desktop backends. That modified engine along with the game code is then ahead-of-time compiled from Java to JavaScript with TeaVM. The result is bundled with all assets into a single self-contained .html file: open it in any browser, no server, JVM, or network required after download.

Working save-load function

You can upload and download your savefiles the normal way you would do it, allowing you to continue your game progress from another device in a flash.

Main features work

Almost every feature in the base Mindustry works as intended (as far as testing can go). Enjoy the same features as the original Mindustry, even on restricted devices. (Unless it is a potato.)

Multiplayer-compatible with other web players

Even multiplayer is coded in, allowing any players to play Mindustry together even without hosting limits (like the Mindustry Tool mod)! (Work in progress, might be buggy)

(Multiplayer with normal Mindustry clients is still a work in progress)

The Host

The host can host a world as how they normally host a LAN world, along with an optional password.

The Player

Find the host's world in the Local Servers section (once again, as if you are joining a LAN world). If a password is required, you are prompted accordingly.

The Gameplay

All players and features works, and it is really simple to build together. The connection uses WebRTC, so most of the time the data won't even be touching my servers, and even if they do, it is encrypted.
